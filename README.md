# Tportfolio

A Jekyll-based portfolio website to showcase your projects and skills.

## 📁 What's Here

This repository now contains a complete Jekyll portfolio website with:
- ✅ Homepage with automatic project listings
- ✅ About page for your information
- ✅ Project showcase with custom layouts
- ✅ Professional styling with custom CSS
- ✅ Responsive, mobile-friendly design

## 🚀 Getting Started

**NEW! See [GUIDE.md](GUIDE.md) for complete instructions on how to edit and customize your portfolio.**

The guide covers:
- How to add new projects
- How to edit your information
- How to customize colors and styling
- How to test locally
- How to publish with GitHub Pages

## 📝 Quick Edits

- **Add a project**: Create a new `.md` file in `_projects/` folder
- **Edit homepage**: Edit `index.md`
- **Edit about page**: Edit `about.md`
- **Change colors**: Edit `assets/css/custom.css`
- **Site settings**: Edit `_config.yml`

## 🌐 Viewing Your Site

Once pushed to GitHub, enable GitHub Pages in your repository settings to publish your site at:
`https://tnorthcutt34.github.io/Tportfolio/`
